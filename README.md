# Task-List
List of assignments that need done and will lock down gaming applications if there is an assignment due in the next 36 hours.

Project Goal (MVP)
- Create the java object of Task which stores fields of information
- Convert the object info and push it into a csv file to store it past the single instance of the program
- Be able to parse info and pull it back from the csv to recreate objects and visualize the stored information
- Create basic CLI interface to view tasks on the list with the given info correlating to them
- Use bash scripts to call on commands like "pkill" to shut down applications when a task is given the urgent status

Final Product (V1.0)
Works as basic user-input task list that shuts down gaming applications when detecting urgent tasks

Future Plans
- Automatically grab assignments from Brightspace to create tasks for them
- GUI Interface
- Snooze capabilities for urgent assignments
